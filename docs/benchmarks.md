# Hook latency benchmarks

Generated by `scripts/bench-hooks.sh` (5 samples per hook). All times in milliseconds. Network-bound hooks (`hooks/ai/*`) are skipped because their latency is dominated by the upstream API round trip and does not reflect the hook code path.

Latency floor on most platforms is ~5–15 ms (bash startup + jq parse). Anything above ~50 ms p99 is worth a closer look — it sits on the synchronous path Claude Code waits on before running the tool call.
